# GeneCMamba1.0
Official implementation of GeneCMamba for spatial transcriptomics‑FFPE stacked section analysis.

This repository corresponds to the manuscript submitted to
**Computational Biology and Chemistry**
> Manuscript ID: CBAC‑D‑26‑03319R1

## Overview
GeneCMamba is an adaptive feature purification framework, which aims to identify gene‑driven cell‑state transitions in the pre‑invasive‑to‑invasive transition zone based on stacked 3D FFPE histology sections and spatial transcriptomics data.
The proposed framework leverages both regulatory and spatial logic to extract biologically‑meaningful representations from spatial gene expression profiles.
